# 塗装数量算出

写真から塗装工事の面積・長さ・箇所を算出する、iPhone現場運用向けのローカル保存型Webアプリです。

## 公開URL

GitHub Pages有効化後：

`https://jzjy88kdfn-hash.github.io/genchou_note/paint-quantity/`

## iPhoneホーム画面への追加

1. 上記URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を押す
4. 表示名「数量算出」を確認
5. 「追加」を押す

## 保存上の注意

- 写真と案件データはブラウザ内へ保存されます。
- 外部サーバーへ案件データを送信しません。
- Safariのデータ削除や端末変更に備え、重要案件はアプリ内のバックアップを保存してください。
