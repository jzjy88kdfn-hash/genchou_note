# 現調台帳・塗装数量算出

このリポジトリには、用途と保存領域が異なる2つのPWAがあります。計算やデータは自動統合しません。

## 1. 現調台帳

公開URL：  
https://jzjy88kdfn-hash.github.io/genchou_note/

現場情報、拾い項目、実測数量、写真、項目別集計、PDF・CSV・JSONバックアップを管理します。

運用順序は次の4工程です。

1. 現場
2. 実測
3. 集計
4. 保存

## 2. 塗装数量算出

公開URL：  
https://jzjy88kdfn-hash.github.io/genchou_note/paint-quantity/

写真上で実寸設定を行い、線・多角形・個数から塗装数量を算出します。

## 分離方針

- 現調台帳と塗装数量算出は別アプリ
- IndexedDB、バックアップ形式、Service Workerを混在させない
- 片方のオフラインキャッシュ更新で、もう片方を削除しない
- どちらも入力・写真を外部サーバーへ送信しない
- 同じ簡易ロックを使用する

## 保存上の注意

通常入力は端末内へ自動保存します。ただしSafariのサイトデータ削除、端末故障、機種変更では失われる可能性があります。現調完了時、大きな修正前、端末変更前には各アプリのバックアップを保存してください。

## 安全性

簡易ロックは日常的な第三者閲覧を防ぐための入口です。GitHub Pagesは公開配信のため、サーバー認証と同じ強度ではありません。
