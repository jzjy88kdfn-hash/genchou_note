# 現調台帳

iPhone現調用の、現場別・項目別・実測集計型PWAです。現場情報、数量、写真、集計、PDF・CSV・バックアップを1本で管理します。

## 正式運用フロー

① 現場 → ② 実測 → ③ 集計 → ④ 保存

### ① 現場
- 現場名・現調日・担当者・工事場所を入力
- 拾い項目の表へ項目名・単位・分類・メモを入力
- 保存現場が1件だけの場合、削除ボタンは無効
- 2件以上ある場合、現場切替で対象を選び「現在の選択現場を削除」

### ② 実測
- 測る項目を選択
- 寸法・同寸法数・控除を入力
- 必要なら写真を最大6枚添付
- 減算・訂正は「－値として登録」にチェック
- 「実測を登録」で確定

### ③ 集計
- 項目別合計と実測件数を確認
- PDF・CSV・集計コピーを出力
- 不正数量や未入力がある場合は出力前に停止

### ④ 保存
- 通常入力は自動保存
- 主保存＋復旧保存＋緊急スナップショット
- 写真は専用IndexedDBストアへ分離保存
- 現調完了時・端末変更前はバックアップ推奨

## 対応単位

- ㎡
- m
- 箇所
- 枚
- 式

## 数量仕様

- ㎡：縦×横、長さ×奥行き、四周×高さ、同寸法数、控除
- m：長さ×同寸法数−控除
- 箇所・枚・式：数量入力
- 負の寸法入力は不可
- 減算は「－値として登録」で最終数量のみマイナス化

## 写真

- 任意、1実測最大6枚
- 長辺1600px目安へ圧縮
- 実測履歴とPDFへ反映
- ブラウザ内保存で、外部サーバーへ写真を送信しません

## 出力・安全性

- PDF
- CSV
- 集計コピー
- JSONバックアップ・復元
- CSV数式注入対策
- SHA-256整合性確認
- 旧形式バックアップ互換

## iPhoneホーム画面で使う

1. GitHub Pagesの公開URLをSafariで開く
2. Safariの共有ボタンをタップ
3. 「ホーム画面に追加」を選択
4. 名前を「現調台帳」にして追加
5. 以後はホーム画面のアイコンから起動

## 古い画面が出る場合

Safariで再読込してください。それでも古い場合は、ホーム画面アイコンを一度削除し、Safariから再度ホーム画面へ追加してください。

## 運用上の注意

Web保存は端末故障やSafariデータ消去まで完全保証するものではありません。重要案件・現調完了時は必ずバックアップを併用してください。
